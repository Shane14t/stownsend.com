How this site is built

A small project, but it covers the same pieces a larger deployment does: source control, CI/CD, DNS, TLS and cost control.

Goal

A fast, secure resume site that costs almost nothing to run and updates automatically when I push a change.

Architecture

Developer (git push)
      |
      v
GitHub repo (main) --> GitHub Actions workflow
                              |
                              v
                 Azure Static Web Apps (Free plan)
                              |
        stownsend.com (DNS at Namecheap, CNAME/validation)
                              |
                      HTTPS (free managed certificate)

Decisions

  • Static HTML/CSS/JS — no server to patch, no database, nothing to exploit.
  • Azure Static Web Apps (Free) — $0 hosting, free managed TLS, built-in GitHub deployment.
  • GitHub Actions — every push to main deploys; pull requests get preview URLs.
  • Custom domain — registered at Namecheap, validated and pointed at Azure with DNS records.
  • Cost control — an Azure budget alert as a safety net, even on a free plan.
