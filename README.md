# stownsend.com

Personal resume and portfolio site for Shane Townsend. Plain HTML/CSS/JS, hosted on Azure Static Web Apps and deployed from GitHub with GitHub Actions.

## Structure

```
index.html                       Home, about, skills, certs, projects, contact
projects/                        Project write-ups
css/style.css                    Styles (light/dark)
js/main.js                       Theme toggle
assets/resume.pdf                Resume (add your own)
staticwebapp.config.json         Azure SWA headers and 404 handling
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8080
```

## Deploy

Push to `main`; the GitHub Actions workflow generated by Azure Static Web Apps publishes the site.
